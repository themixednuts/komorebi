Disposable Wayfinder probe · event-first · public Windows APIs only

When has a user-driven Windows desktop switch actually settled?

This prototype models the measured manager design: a documented WinEvent wakes a bounded public-API verification burst, three equal cohort samples settle it, and sampling stops. It never enumerates, orders, creates, or switches Windows desktops.

Selected ownership boundary

WindowsDesktopWakeAdapter owns the WinEvent hook and callback filtering. PublicVirtualDesktopPort classifies HRESULTs and produces cohort snapshots. DesktopSettler is pure temporal logic. DesktopVisibilityPlanner receives only committed generations or explicit unavailability. Explorer restart advances the observation epoch and invalidates every candidate.
